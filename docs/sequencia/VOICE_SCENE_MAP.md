# VOICE_SCENE_MAP · voz × cena × passagem (régua do roteiro, provisória)

Os tempos abaixo são **estimativas** (2,4 palavras/s). Não são timestamps: quando a voz chegar, o Scribe mede cada palavra e estes números são substituídos (ver `ONSCREEN_VOICE_RULES.md` §4 e `PLANO_DE_RENDER.md`).
